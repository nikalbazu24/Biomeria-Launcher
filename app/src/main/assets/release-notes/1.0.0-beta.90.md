### NeoForge para Minecraft Java 1.21.4

- Al crear o gestionar una instancia de Minecraft Java **1.21.4**, puedes elegir **NeoForge 21.4.161**. PRISSMA descarga los archivos en segundo plano. El primer arranque prepara el cliente y escribe el progreso en el registro.
- El Taller comprueba la versión y el cargador antes de instalar mods de NeoForge y sus dependencias. Puedes seguir el progreso desde **Descargas**.
- El arranque de NeoForge y la detección de AppleSkin se comprobaron en Linux. Esta integración está abierta a pruebas en Android ARM64.
