### Mando físico en Minecraft Java

- En los menús, mueve el cursor visible con el stick, confirma con A y vuelve atrás con B.
- En un mundo, el stick izquierdo mueve al personaje y el derecho controla la cámara. A salta, B agacha y Start abre la pausa.
- L1 y R1 recorren la barra rápida. L2 usa el objeto y R2 ataca.
- Los gatillos que se reportan como eje y botón generan un solo clic. Las entradas se liberan al perder el foco.
