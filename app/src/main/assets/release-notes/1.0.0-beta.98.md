### Biblioteca de Bedrock por instancia

- Importa archivos `.mcpack`, `.mcaddon` y `.mcworld` desde el Taller. BIOMERIA comprueba el archivo y guarda una copia en la instancia, disponible cada vez que vuelvas a abrirla.
- Filtra por tipo, exporta copias y quita archivos guardados. Si vuelves a importar el mismo archivo en una instancia, BIOMERIA te muestra la copia que ya existe.
- Si tienes Minecraft Bedrock instalado, puedes abrir desde el Taller uno de los archivos guardados para que el juego lo importe.
