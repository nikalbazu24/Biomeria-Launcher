### Cuentas Microsoft en Java

- El perfil de jugador permite vincular una cuenta Microsoft con código de dispositivo. BIOMERIA comprueba el perfil de Minecraft Java y usa su nombre, UUID y sesión al iniciar el juego.
- BIOMERIA cifra la sesión en el dispositivo, la renueva cuando caduca y oculta el token en sus registros de lanzamiento. Puedes cerrar sesión o elegir **Offline** para usar tu nombre local.
- Las compilaciones sin un ID incluido muestran el campo para introducir el ID público de una aplicación autorizada para Minecraft Java.
