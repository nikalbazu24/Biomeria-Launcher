### Controles, perfil y versiones

- El táctil permanece visible aunque uses mando. Toca una de las nueve casillas para seleccionar un objeto. L1 y R1 se calibran con la sensibilidad de rueda del juego.
- Antes de jugar, abre Controles y HUD para configurar botones, activar el contador de FPS y ajustar la opacidad de pausa. También puedes ajustar el HUD en partida.
- La tarjeta del jugador abre un perfil local con foto, nombre, descripción y preferencias de juego e idioma.
- El catálogo incluye las versiones publicadas por Mojang. Se amplía el arranque Java 21 a 1.20.5–1.21.11 y se ofrecen 1.20.1 y 1.20.4 como Vanilla en pruebas. Las demás aparecen con su estado de compatibilidad.
