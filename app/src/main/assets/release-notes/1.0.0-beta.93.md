### Taller de Rust para Starling

- En **Rust → Taller → Importar mod** puedes elegir un `.hmod` local. PRISSMA comprueba el contenido del ZIP y el manifiesto de la API 0.2 de Horizon.
- Después de verificarlo puedes ver el nombre, la versión y el tipo de mod, y pulsar **Enviar a Starling**. Starling muestra el resultado y gestiona la activación. Los mods nativos se compilan desde sus propias opciones.
- Los importadores de Bedrock y Starling comparten la preparación de archivos y la verificación del ZIP.
