### Doble pantalla para Java

- Activa **Controles y HUD → Doble pantalla** en tu instancia. El juego sigue en su pantalla y PRISSMA abre un panel en la secundaria si Android la habilita para presentaciones.
- En **Minecraft Java 1.21.4 con Fabric**, toca las ranuras para mover objetos y usa el crafteo personal 2×2, la barra rápida y el mapa que tengas equipado. Fabric carga el panel desde PRISSMA.
- La pestaña **Opciones** reúne los controles táctiles, el contador de FPS y la opacidad del botón de pausa. En otras versiones de Java, el panel ofrece la barra rápida y esos ajustes.
