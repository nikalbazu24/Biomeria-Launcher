### Reporte automático de errores

- **Si Biomeria o el juego se cierran, el error le llega solo al desarrollador** para poder arreglarlo. El mismo error de varios equipos se junta en un solo aviso.
- **Tu privacidad:** no se envía tu cuenta de Microsoft, tu nombre de jugador, correos ni tus mundos. Solo el error, la versión de Biomeria y el modelo de tu equipo.
- **Puedes apagarlo** en Ajustes, «Enviar errores automáticamente».
