### Libro de recetas en la pantalla inferior

- Abre una mesa 3×3 y toca **Recetas** en el panel inferior. El libro muestra las recetas desbloqueadas en Minecraft Java 1.21.4 con Fabric.
- Busca por nombre con el teclado táctil, filtra las recetas que puedes fabricar y consulta las cantidades y alternativas de los ingredientes que faltan.
- **Colocar ingredientes** usa el llenado de Minecraft. Recoge el resultado en la mesa cuando esté listo.
