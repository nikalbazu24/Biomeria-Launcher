### Quilt

- **Nuevo cargador: Quilt.** Al crear o editar un mundo Java ya puedes elegir Quilt, en todas las versiones que tienen Fabric.
- **Quilt también usa los mods de Fabric**, así que en el Taller ves los mods de ambos. Si un mod tiene versión propia para Quilt, Biomeria la prefiere.
- Los modpacks para Quilt, de Modrinth o CurseForge, ahora también se importan.
- La doble pantalla y el mapa siguen siendo para 1.21.4 con Fabric.
