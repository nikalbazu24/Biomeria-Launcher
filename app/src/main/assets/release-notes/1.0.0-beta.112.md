### Sala por internet

- Entra a un mundo de un jugador en **Java 1.21.4 con Fabric**. Abre **Atajos → Por internet → Crear invitación**.
- Copia la dirección de **bore.pub**. Tus amigos pueden entrar desde otra red usando **Multijugador → Conexión directa** en un cliente Java compatible.
- Vuelve a la partida con el enlace activo. Para retirarlo, abre **Por internet → Cerrar enlace**. Al salir del mundo o cerrar BIOMERIA se desconecta el relay automáticamente.
- **Sala LAN** sigue disponible en Atajos para quienes estén en tu red.

El tráfico de la sala por internet pasa por el relay público de Bore mientras el enlace esté activo.
