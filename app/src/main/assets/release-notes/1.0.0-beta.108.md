### Recetas y mapa con mando en la pantalla inferior

- Abre una mesa de crafteo, mantén **Select** medio segundo y suéltalo para pasar el mando a la pantalla inferior. Pulsa **R1** para abrir **Recetas**.
- Usa la cruceta o el stick izquierdo para recorrer las recetas, **X** para mostrar solo las fabricables y **A** para entrar en una receta. Pulsa **A** en el detalle para colocar ingredientes. PRISSMA vuelve a la mesa con el resultado resaltado. Pulsa **A** para recogerlo y elige dónde guardarlo.
- **B** vuelve del detalle a la lista y de la lista a la mesa. **Select** devuelve el mando al juego.
- En **Xaero’s World Map** abierto abajo, usa el **stick derecho** para desplazar el mapa y **X/Y** para controlar el zoom.

El flujo usa **Minecraft Java 1.21.4 con Fabric**. El desplazamiento con stick se verificó con **Xaero’s World Map 1.46.0**.
