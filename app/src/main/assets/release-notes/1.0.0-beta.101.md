### Cuentas Ely.by en Java

- Vincula tu cuenta desde **Perfil de jugador → Ely.by**. Si la cuenta usa 2FA, BIOMERIA solicita el código del autenticador.
- BIOMERIA conserva cifrada la sesión y la verifica al abrir Java. Ely.by se usa en servidores compatibles cuando seleccionas ese tipo de cuenta.
- Microsoft y Offline siguen disponibles. El agente incluido se carga en Java cuando eliges Ely.by. [Código fuente de authlib-injector 1.2.8](https://github.com/yushijinhun/authlib-injector/archive/refs/tags/v1.2.8.tar.gz)
