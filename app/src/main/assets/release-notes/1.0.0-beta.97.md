### Rust integrado en BIOMERIA

- La tarjeta de Rust abre el motor ARM64 de Starling 0.9.0 dentro de BIOMERIA. En el primer arranque, el motor prepara los archivos de Minecraft Java 26.3.
- El Taller de Rust permite elegir un `.hmod` de Horizon API 0.2. El motor verifica el paquete y gestiona su instalación.
- Los diagnósticos de Rust se abren desde su tarjeta. Actualiza BIOMERIA desde Ajustes para recibir futuras versiones del motor.
