### Taller de Bedrock

- Abre **Taller** en tu tarjeta Bedrock para importar paquetes `.mcpack`, complementos `.mcaddon` y mundos `.mcworld` desde el selector de archivos de Android.
- PRISSMA verifica el archivo y ofrece **Abrir en Minecraft** para enviarlo a la aplicación elegida en la tarjeta. Minecraft muestra el resultado de la importación dentro del juego.
- El Taller informa si el archivo está dañado o si Android no puede abrir un importador para ese formato.
