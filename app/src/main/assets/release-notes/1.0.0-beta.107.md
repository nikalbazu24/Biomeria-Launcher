### Control del panel inferior con mando

- Mantén **Select** medio segundo y suéltalo para pasar el mando al panel inferior. Pulsa **Select** otra vez para volver al juego.
- Usa la cruceta o el stick izquierdo para recorrer las ranuras. Pulsa **A** para tomar o colocar, **X** para dividir o colocar una unidad y **Y** para mover rápido una pila. **B** cierra el menú y devuelve el mando al juego.
- En el panel de inventario, **L1/R1** cambian de pestaña. Cuando el mapa de Xaero está abierto abajo, **X/Y** controlan el zoom.
